# Contributing

This is an All Rights Reserved project. Contributions may be accepted through pull requests, but no license to the project is granted by contribution or public visibility.

1. Branch from `development` using `feat/`, `fix/`, `docs/`, or `chore/`.
2. Use Conventional Commits.
3. Add tests and documentation with behavioral changes.
4. Do not include secrets, production URLs, credentials, cookies, customer data, or fetched private content.
5. Open a pull request into `development` and wait for required checks.
