# UI Style Reference

## Primary reference

- [Vibe Coding Starter](https://github.com/majestic44/vibe-coding-starter) is the visual and interaction
  reference for future PagePulse UI work.

Use it to inform the overall quality bar: clear hierarchy, deliberate spacing, polished responsive behavior,
cohesive component states, and purposeful motion. PagePulse remains a monitoring product with its own information
architecture, content, branding, accessibility requirements, and security boundaries.

## Use boundaries

- Treat the reference as inspiration, not a dependency or a template to copy wholesale.
- Do not copy source code, images, copy, logos, or other branded assets into PagePulse without a separate review.
- Preserve keyboard navigation, visible focus, reduced-motion support, responsive layouts, and WCAG 2.2 AA goals.
- Keep authenticated and operational screens information-dense, predictable, and suitable for long-running work.
- If a future change reuses a substantive portion of the reference's MIT-licensed code, retain the applicable
  copyright and license notice in that change.

## Review checklist

When implementing or reviewing UI work, compare the result against this reference for visual polish while verifying
that PagePulse-specific flows remain clear and accessible:

1. A clear primary action and readable visual hierarchy.
2. Consistent spacing, typography, colors, and state feedback.
3. Desktop and narrow-viewport usability without hidden essential actions.
4. Keyboard, focus, contrast, and reduced-motion behavior.
5. No disclosure of credentials, session details, private target content, or internal diagnostic data.
